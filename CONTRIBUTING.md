# Contribuindo

## Fluxo

1. Abra uma issue para alinhar mudanças funcionais ou riscos.
2. Crie uma branch curta a partir de `main`.
3. Faça alterações pequenas e rastreáveis.
4. Execute as validações locais.
5. Abra um pull request descrevendo objetivo, evidências, riscos e reversão.

## Commits

Use mensagens objetivas, por exemplo:

- `feat(simulator): adiciona cenário de perda`
- `fix(storage): trata transação incompleta`
- `test: cobre regra de detecção`
- `docs: atualiza arquitetura`
- `chore(ci): ajusta validação`

## Licença das contribuições

Ao enviar uma contribuição para este repositório, você concorda que ela será disponibilizada sob a [Apache License 2.0](LICENSE), conforme os termos aplicáveis a contribuições descritos nessa licença.

## Segurança

Utilize somente dados sintéticos e identificadores genéricos. Não inclua informações de plantas, equipamentos ou redes reais.
