# Política de segurança

## Escopo

Este repositório é demonstrativo e utiliza dados sintéticos. Não deve ser conectado diretamente a redes, PLCs, bancos ou sistemas industriais reais sem uma avaliação técnica e de segurança específica.

## Relato de vulnerabilidades

Não abra issue pública para credenciais, dados pessoais ou vulnerabilidades exploráveis. Utilize o recurso **Report a vulnerability** na aba **Security** do repositório.

Inclua:

- descrição e impacto;
- versão ou commit afetado;
- passos de reprodução com dados fictícios;
- evidências sem credenciais ou dados reais;
- proposta de mitigação, quando disponível.

## Dados proibidos

Não envie:

- credenciais ou arquivos `.env`;
- endereços e rotas de redes industriais reais;
- nomes e tags reais de equipamentos;
- programas ou backups de PLC;
- bancos de produção;
- telas ou documentos proprietários;
- dados pessoais ou informações de clientes.
