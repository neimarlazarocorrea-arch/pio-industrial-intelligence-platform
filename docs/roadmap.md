# Roadmap

## Fase 1 — Fundação pública

- [x] estruturar governança, segurança e validações iniciais;
- [x] documentar aplicações demonstrativas;
- [x] utilizar exclusivamente cenários e dados sintéticos;
- [ ] concluir o Gate de Publicação do repositório arquitetural.

## Fase 2 — Collector independente

- [ ] consolidar o contrato mínimo de amostras;
- [ ] implementar configuração e aprovação de fontes sintéticas;
- [ ] validar qualidade, sequência e lacunas;
- [ ] implementar logs, checkpoint e recuperação;
- [ ] validar backup, exportação e reprocessamento.

## Fase 3 — Operação & Analytics

- [ ] versionar regras operacionais;
- [ ] separar evento válido, inconclusivo e dado bruto;
- [ ] calcular indicadores com rastreabilidade;
- [ ] validar histórico, recorrência e diagnóstico.

## Fase 4 — Aplicações reproduzíveis

- [ ] publicar demonstração do Industrial Microstop Monitor;
- [ ] publicar demonstração do Industrial Hourly Production Dashboard;
- [ ] documentar execução e evidências;
- [ ] criar a primeira release pública.

## Evolução futura

- observabilidade;
- testes de carga com dados sintéticos;
- contratos de API local;
- armazenamento escalável quando houver evidência de necessidade;
- novos módulos avaliados individualmente pelo Gate de Publicação.

> O roadmap descreve direção técnica, não compromisso de prazo. Itens planejados não representam funcionalidades concluídas.
